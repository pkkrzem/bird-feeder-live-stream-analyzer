# 🐦 Bird Feeder Live Stream Analyzer

A real-time AI computer vision system designed to detect, track, and identify bird species from live bird feeder camera streams (via YouTube).

This project combines **YOLOv8** for object detection, **Kalman Filters** for robust tracking, and a **Transformer-based EfficientNet** model to identify over 500 bird species with high accuracy.

## ✨ Features

*   **Real-time Detection:** Uses YOLOv8 to detect birds, optimized with multi-scale inference for identifying small or distant birds.
*   **Intelligent Tracking:** Implements a custom Kalman Filter to smooth erratic bird movements and maintain IDs across frames.
*   **Species Identification:** Optional integration with `dennisjooo/Birds-Classifier-EfficientNetB2` (99.1% accuracy on 525 species) to classify the bird.
*   **Data Logging:** Automatically logs bird visits to a CSV file (`bird_log.csv`) including timestamp, species, confidence, and tracking duration.
*   **Photo Capture:** Automatically saves high-quality crops of identified birds to a `bird_photos/` directory.
*   **Adaptive Processing:** Includes "Standard" and "Enhanced" modes to balance performance vs. detection sensitivity.

## 🚀 Usage

### Step 1: Get the Stream URL
This program requires a direct HLS (M3U8) stream URL, not a standard YouTube link. Use `yt-dlp` to generate this.

Open your terminal/command prompt and run:
```bash
yt-dlp -g https://www.youtube.com/watch?v=YOUR_VIDEO_ID
```
*Copy the URL output (it will be a long string starting with `https://manifest.googlevideo.com...`).*

### Step 2: Run the Analyzer
```bash
python bird_feeder_live_stream_analyzer.py
```
### Step 3: Configure at Runtime

The application will prompt you for settings in the console:
1. **Paste URL**: Paste the long URL you copied in Step 1.
2. **Processing Method**: Choose Single-threaded (recommended) or Two-threaded.
3. **Enable Bird ID**: Type 'y' to load the classification model (requires internet on first run to download ~30MB model).
4. **Detection Mode**:
    * `Standard`: Faster, good for close-up birds.
    * `Enhanced`: Uses multi-scale detection and contrast enhancement (better for small birds, but higher CPU usage).
  
## 📊 Output
* **GUI Window**: Shows the live stream with bounding boxes.
    * Green Box: Identified bird (Species name displayed).
    * Yellow Box: Stable tracking candidate.
    * Orange Box: Searching/Tracking.
* **CSV Log**: Check `bird_log.csv` for a history of sightings.
* **Photos**: Check the `bird_photos/` folder for saved snapshots.

## 🧠 Technical Details

### Models Used
* Detection: [YOLOv8s](https://github.com/ultralytics/ultralytics) (Small version). It downloads automatically on first run.
* Classification: [EfficientNet-B2](https://huggingface.co/dennisjooo/Birds-Classifier-EfficientNetB2) trained on 525 bird species.

### Identification Logic
The system doesn't just classify every frame (which would be slow). Instead:
1. It detects a bird and starts a Track.
2. It assesses the "stability" of the bird using the Kalman Filter velocity.
3. It captures the best quality frames (based on sharpness and contrast).
4. Once the bird is stable and tracked for a specific duration, it sends the best frame to the Classifier.
5. It enforces a "Cooldown" to prevent logging the same bird repeatedly within a few minutes.

## ⚠️ Troubleshooting
* **"Transformers library not found"**: You are running in detection-only mode. Run `pip install transformers torch pillow` to fix.
* **Stream closes immediately**: The YouTube URL generated by `yt-dlp` expires after a few hours. You must generate a new one if the stream stops.
* **Laggy Video**: Switch to "Standard" mode or lower the `CAPTURE_FPS_LIMIT` in the config.
